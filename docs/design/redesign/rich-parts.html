contr chat: richer content for orchestration

One coordinator answer in the chat, then each part alone. All parts use only the contr tokens: ink for the data, red only for what waits for you, and state shown by glyphs and shapes. The one exception is PR and issue chips: they use GitHub's state colors, from the app's theme tokens, so you see open, merged and closed at a glance. Each part says where its data comes from (GitHub, hc or the orchestration tool, never the screen) and what the agent writes for it. A part marked now is in the chat today and gets a new look; a part marked new is a proposal. All data on this page is an example.
