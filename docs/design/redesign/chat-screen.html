contr chat: Herdr layout, contr tokens

The layout is Herdr's as it is now: a full-height sidebar with the machine switch, Projects, agents and workers, usage and Settings; one tab bar with Files and Changes; Chat and Terminal at the top right; the reply box at the foot. The colors, type, glyphs and the question card come from the contr design system. The glass is drawn as solid fills, as the system says for reduced transparency. Red marks only the worker that waits for you.
