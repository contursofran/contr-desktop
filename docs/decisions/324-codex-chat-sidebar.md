# Show Codex chats in Projects

Show Codex in Chat. Send and receive App Server messages through
standard input and output. Keep the Chat and Terminal switch for
Claude Code and Shell.

Group a Codex chat by the working directory from App Server. Use the
same Git project lookup as for hc agents. Show the thread name when
Codex supplies it, or the first prompt. Use the saved open tabs to read
thread details on restart.
