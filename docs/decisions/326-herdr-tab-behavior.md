# Use Herdr tab navigation

Use the open tab order for numbered keys, previous and next, and the
vertical wheel over the tab strip. Previous and next wrap. Horizontal
scroll still moves the strip.

Keep the current drop line and cancel a drag released outside the tab
strip. Alt with Left or Right moves the focused tab and wraps.

The reference is [Herdr's desktop tabs](https://github.com/herdrdev/herdr-app/blob/317e673f1f1568b876cbaa0b41dabeb9153ecbea/defaults/mods/tabs/main.js)
and its [key map](https://github.com/herdrdev/herdr-app/blob/317e673f1f1568b876cbaa0b41dabeb9153ecbea/defaults/keys.macos.json).
